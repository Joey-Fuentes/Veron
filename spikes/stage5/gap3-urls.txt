# The packages the dependency scan says are REQUIRED and absent.
#
# 231 declared names are not in the set, and almost all of them are optional:
# platform frameworks that never apply here (appleframeworks, cocoa, android,
# directx), features we disable by policy (x11, xcb, systemd, qt6, gtk+), test
# harnesses (check, cmocka, gtest, valgrind), sub-libraries of packages we
# already have (libbrotlidec is brotli's, hogweed is nettle's, libavcodec is
# ffmpeg's), and a long codec tail nothing on the browser path needs.
#
# THESE ARE THE ONES THAT ARE NOT OPTIONAL:
#
#   gmp     nettle builds hogweed against it, hogweed is nettle's public-key
#           half, and gnutls needs hogweed. Without gmp there is no TLS.
#   libelf  mesa requires it -- the mesa configure spike found this months ago
#           and it was written down and then not acted on.
#   libcap  bubblewrap needs it, and bubblewrap is WPE WebKit's sandbox as
#           well as the tool a user rebuilds Veron with.
#   ogg     gst-plugins-base's audio path. Vorbis is the container's codec and
#   vorbis  ogg is the container; neither is optional for basic playback.
#   scdoc   foot, fuzzel and seatd generate their man pages with it. Small,
#           and cheaper to have than to patch three build files.
#
# AND EACH OF THESE IS PROBED FOR ITS OWN DEPENDENCIES TOO. Adding a package
# to close a gap has twice opened another -- file needed nothing, but bash
# pulled in nothing while glib needed bash, and libudev-zero was itself only
# found by reading declarations. A package added without reading what IT
# declares is the next gap, discovered later and more expensively.
