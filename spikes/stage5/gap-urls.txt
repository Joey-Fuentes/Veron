# WHAT THE SCAN FOUND. `probe deps` read the dependencies every remaining
# package declares -- a column `probe batch` had been writing all along and
# nothing had ever read -- and the biggest result was that FOUR packages want
# libudev and nothing provides it:
#
#     libudev   4x   libinput, mesa, wlroots, yambar
#
# busybox does not cover this. Its `mdev` is a hotplug helper that creates
# device nodes; what these four link against is libudev.so, a C library with
# udev_enumerate_scan_devices() and udev_monitor_receive_device(). libinput's
# whole device model is udev-based, so no libudev means no input, which means
# no compositor. libudev-zero implements that API with no daemon, reading
# /sys directly -- written for exactly this case.
