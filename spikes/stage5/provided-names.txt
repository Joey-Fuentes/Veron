# Names a package may declare that the set already provides.
#
# Two kinds, and both matter or the unmet-dependency report is useless noise:
#
#   SUB-LIBRARIES a package ships itself -- wayland provides wayland-client,
#     wayland-server, wayland-egl and wayland-cursor, so a package declaring
#     any of those is satisfied by wayland
#   SYSTEM NAMES that come from libc, the toolchain or the sysroot -- m, dl,
#     pthread, rt, iconv, openssl
#
# Without these every report would list forty names that are already covered
# and the real gaps -- alsa, hwdata, libdisplay-info -- would be buried.
